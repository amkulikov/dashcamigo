Help us check video exports

This test checks how your browser saves video at different quality settings.

  1. Open this file in Chrome on the computer where you noticed the problem.
  2. Click Run test and keep this tab open. It may take a few minutes.
  3. Click Download report and attach the file to your reply.

The test creates its own moving pictures. You don’t need to select any recordings or install anything. Everything runs offline; nothing is sent automatically.

Ready when you are.

Technical details

Compares native WebCodecs with bundled Mediabunny using H.264 at 5 and 32 Mbps, including VBR, CBR, resolution and software preference controls. A supported setting does not guarantee the target bitrate. Synthetic results may differ from real recordings.
